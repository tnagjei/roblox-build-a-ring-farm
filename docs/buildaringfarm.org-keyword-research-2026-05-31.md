## 第七章：Top 3 关键词定方向

### 1. Build A Ring Farm PLANTRUSH code，中文解释：PLANTRUSH 兑换码

推荐动作：

* `/codes/` 加 source matrix，中文解释：来源矩阵。
* PLANTRUSH 状态保持 pending in-game verification，中文解释：待游戏内验证。
* claimed reward，中文解释：声称奖励，写 Plant Rush Boss Box。
* 加 FAQ：Is PLANTRUSH active here? 中文解释：PLANTRUSH 在本站是否已验证有效？答案是 no，pending。

### 2. Build A Ring Farm Plant Rush Boss Box，中文解释：Plant Rush Boss Box 奖励

* 不要写成 verified reward，中文解释：已验证奖励。
* 如果没有游戏内截图，继续禁止放进 verified active table。

### 3. Build A Ring Farm ring multiplier calculator，中文解释：戒指倍率计算器
